# BtBatteryTray

[English](README.md) · [Русский](README.ru.md) · **Українська**

Невеликий застосунок для системного трею Windows: показує заряд Bluetooth-пристроїв — навушників, колонок, мишки, клавіатури, геймпада — прямо в області сповіщень.

## Що він робить

- показує **лише фактично підключені** пристрої;
- малює заряд вибраного пристрою-**цілі** в іконці трею, а якщо ціль не вибрано — найнижче значення;
- виводить назви пристроїв та їхній заряд у підказці трею;
- попереджає про низький заряд;
- темна й світла теми меню;
- інтерфейс **англійською**, **російською** та **українською**;
- за бажанням запускається разом із Windows;
- без інсталятора, без залежностей і без доступу до мережі.

Список оновлюється раз на 60 секунд. Пункт **«Оновити зараз»** запускає оновлення негайно.

## Завантажити й запустити

1. Завантажте `BtBatteryTray.exe` зі сторінки [Releases](https://github.com/ProfessorSovers/btbatterytray/releases).
2. Покладіть файл у будь-яку теку та запустіть.
3. В області сповіщень з'явиться іконка. Клік по ній відкриває меню.

Більше нічого не потрібно: ні інсталятора, ні .NET чи Rust, ні додаткових DLL, ні налаштувань. Файл самодостатній, а налаштування зберігаються в реєстрі (див. нижче), тож його можна вільно переносити та перейменовувати.

Для оновлення просто замініть файл на новіший і перезапустіть застосунок. Автооновлення та фонової служби немає.

## Використання

Меню відкривається кліком по іконці в треї.

- **Ціль** — за яким пристроєм стежити в іконці: конкретний пристрій або *«Авто (найрозрядженіший)»*.
- **Мова** — англійська / російська / українська.
- **Тема** — темна або світла.
- **Оновити зараз** — запросити оновлення негайно.
- **Автозапуск** — додати або прибрати запис з автозавантаження.
- **Вихід** — закрити застосунок.

У підказці трею перелічені всі підключені пристрої із зарядом — вона з'являється при наведенні на іконку.

Налаштування зберігаються окремо для користувача:

```text
HKCU\Software\BtBatteryTray
```

Діагностичний лог записується у:

```text
%LOCALAPPDATA%\BtBatteryTray\log.txt
```

Лог обмежений приблизно 200 КБ і містить лише назви пристроїв, заряд і тайминги. Мережевих запитів і телеметрії в застосунку немає.

## Обмеження

Заряд надає сама Windows — через Bluetooth-адаптер, пристрій та його драйвер. Тому:

- сполучений пристрій показується лише поки він справді підключений;
- підключений пристрій може бути відсутнім, якщо Windows взагалі не повідомляє його заряд;
- значення може надходити із затримкою: як часто його надсилати, вирішує сам пристрій.

Якщо Windows зовсім не може повідомити статус підключення, застосунок показує всі пристрої з доступним зарядом, а не порожній список.

Застосунок не звертається до хмарних сервісів виробників і не обходить Bluetooth-API Windows.

## Діагностика

Стане в пригоді при повідомленні про проблему:

```text
BtBatteryTray.exe --conntest      # знайдені пристрої, вердикт підключення та час перевірки
BtBatteryTray.exe --rendertest    # малює меню у BMP-файли в поточній теці
BtBatteryTray.exe --balloontest   # одразу показати сповіщення про низький заряд
                                  # (відсоток синтетичний: реальний тригер — нижче 20%;
                                  #  свій рівень: --balloontest=5)
```

Перші два режими самостійні: друкують або записують файл і завершуються, не запускаючи іконку в
треї. `--balloontest` показує сповіщення на кілька секунд і завершується; його можна запускати,
навіть коли застосунок уже працює.

## Збірка з вихідного коду

Цей розділ — для розробників. Якщо ви просто хочете користуватися застосунком, завантажте готовий файл із Releases — див. вище.

Вимоги:

- Windows 10 або новіша (x64);
- Rust і Cargo: <https://rustup.rs/>.

```text
cargo build --release
```

Готовий файл з'явиться в `target\release\BtBatteryTray.exe`.

Запуск тестів:

```text
cargo test --locked
```
